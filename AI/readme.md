# AI Tools & Resources

## 1. AI Subscriptions

- **Junior**: [Cursor](https://cursor.com/)
- **Senior**: [Claude.ai](https://claude.ai)

## 2. Command Line Interface

- [Claude Code CLI](https://code.claude.com/docs/en/cli-reference)
- [Warp Terminal](https://www.warp.dev/)

## 3. Free AI Tools

- **ChatGPT / Gemini** - Good for learners and beginners
- **Ollama / DeepSeek / Qwen** - Self-hosted options
- [Kaggle](https://www.kaggle.com/) - 30 hours free/week

## 4. Project Planning & Architecture

For analyzing requirements and designing architecture, task plans, and roadmaps in large software projects:

- **Claude**: `/ultra plan` mode
- [Grill-me Skill](https://github.com/.../skills/productivity/grill-me/SKILL.md)

## 5. Project Configuration

Each project should have:
- Separate `claude.md`
- Separate `skill.md`
- Separate `agent.md`

## 7. Architecture Design & Diagrams

## 8. Code Review

- **CodeRabbit**: [coderabbit.ai](https://www.coderabbit.ai/)
- **Claude Commands**:
  - `/review` - Standard code review
  - `/ultrareview` - In-depth code review
  - `/code-review` - Detailed review
- **Validation Loop**: Unit test generation → Run test suite → Visual tests with [Playwright Plugin](https://claude.com/plugins/playwright)

## 9. Security Vulnerability Scanning

- [Snyk Code](https://snyk.io/)
- **Claude**: `/security-review` command

## 11. Autonomous AI & Agents

- **Multica.ai** - AI agent-integrated Kanban board and task management: [multica.ai](https://multica.ai/)
- **Paperclip** - Open-source multi-agent orchestration: [paperclip.ing](https://paperclip.ing/)
- **OpenClaw** - Chat-based agent and automation: [openclaw.ai](https://openclaw.ai/)
- **Hermes Agent** - Similar to OpenClaw with feedback and self-learning: [GitHub](https://github.com/nousresearch/hermes-agent)
