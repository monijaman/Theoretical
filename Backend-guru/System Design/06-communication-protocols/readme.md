# 6. Communication Protocols

This section compares the main ways systems talk to each other.

## What this section covers

- REST vs GraphQL vs gRPC
- WebSockets vs SSE vs long polling

## How to study it

1. Match the protocol to the communication need.
2. Compare request-response APIs with streaming APIs.
3. Think about trade-offs in flexibility, performance, and complexity.
