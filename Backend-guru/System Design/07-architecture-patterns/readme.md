# 7. Architecture Patterns

This section explains the bigger design choices behind the system shape.

## What this section covers
- Monolith vs microservices
- Microservices architecture
- Multi-tenant architecture

## How to study it
1. Understand the problem before choosing the pattern.
2. Compare the operational cost of each approach.
3. Ask whether the team and product really need a complex distributed architecture.
