# 4. Caching

Caching is one of the most practical ways to improve system performance without rewriting the whole architecture.

## What this section covers

- Caching strategies: where and how to cache
- Cache eviction policies
- Cache invalidation
- CDN architecture for global content delivery

## How to study it

1. Understand why caching helps in the first place.
2. Learn the difference between cache hit, miss, and stale data.
3. Always connect caching choices to freshness and complexity trade-offs.
